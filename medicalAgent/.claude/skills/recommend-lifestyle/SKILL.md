# Recommend Lifestyle Skill

根据诊断结果推荐生活方式调整建议。

## 功能

- 基于诊断查询生活方式建议
- 使用 Milvus 向量数据库检索
- 提供个性化的生活方式指导

## 使用方式

```python
result = await recommend_lifestyle(diagnosis="高血压")
```
