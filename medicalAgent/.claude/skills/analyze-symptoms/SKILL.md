# Analyze Symptoms Skill

分析症状模式，识别可能的疾病关联。

## 功能

- 症状分类识别（呼吸/消化/神经/心血管/肌肉骨骼）
- 关联可能疾病
- 知识库增强分析

## 使用方式

```python
result = await analyze_symptoms(symptoms="咳嗽、发热、头痛")
```
