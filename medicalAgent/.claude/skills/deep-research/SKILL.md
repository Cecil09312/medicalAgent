# Deep Research Skill

对医学问题进行深度研究，使用迭代分析生成综合报告。

## 功能

- 使用 DeepResearchWorkflow 进行深度研究
- 多轮迭代分析
- 生成结构化研究报告
- 评估证据等级

## 使用方式

```python
result = await deep_research(query="糖尿病最新治疗方法", max_iterations=2)
```
